# BUG-057～060 复现、修复与验证

四项均确认存在，已在本地修复。保持此前 `--verbose` 聚焦输出改动及台账内容；本轮不连接、上传、重载或修改远端。

| 条目 | 根因与修复 |
| --- | --- |
| BUG-057 | 原摘要丢失端口/来源运算符、协议、族与链挂接信息。两阶段共用等价的自包含解析/判定实现，保留未知条件，对同一 input 基链内的新 TCP 连接按族、按序取证，IPv4/IPv6 分别满足后才通过。不使用 regular/forward 链拼接证据；命名集合、链跳转和无法解释的表达式不通过。公网关闭复用这一取证路径。 |
| BUG-058 | 原判断仅要求字符串包含 publickey。现要求 AuthenticationMethods 明确为 publickey；逗号多阶段与未核验其它机制的 any 均不宣称单公钥目标完成。 |
| BUG-059 | 原 stage2 把所有 systemd TCP listener 都归入 SSH。现仅关联 active ssh.socket 的 TCP Listen 地址/端口，并继续合并 ssh.socket 自身的端口事实；其它 systemd socket 不计入 SSH。 |
| BUG-060 | 原账户命令对非整数 old_port 固定回退22。现优先明确旧端口，其次当前 SSH 会话端口，无会话时使用声明目标；账户安装、登录/sudo 验证和 tailnet 接入同步使用该入口。 |

验证过程：先增加反例，在修改生产代码前确认原错误；再修复并增加相邻负例与正常规则正例。原混合地址夹具错误地把 IPv6 放在 ip saddr 中，已改为真实的按族规则，未通过放宽生产解析器来迁就夹具。

最终验证：

- Debian WSL `python3 tests/run-tests.py`：159 项全部通过，无跳过；新增16项（含参数化子用例）。
- 真实 nft 内核 JSON：在独立用户/网络命名空间内加载合法双栈拒绝、否定端口、UDP 拒绝和仅 IPv4 拒绝，确认合法规则通过、错误规则不误报。
- 三脚本 bash -n、ShellCheck warning 级检查通过。
- JSON 完整步骤/恢复信息、只读命令白名单、故障停止、恢复程序和聚焦输出的既有回归均通过。

边界：当前是受支持规则布局的保守证明器，不是通用 nft 符号执行器；未知复杂布局可能保持未通过。新的判定不替代实际新公钥会话、救援演练及跨重启外部允许/拒绝来源验证。远端仍是此前版本，不能以本地修复声称服务器已完成验收。

语义参考：[nftables 官方手册](https://netfilter.org/projects/nftables/manpage.html)、[OpenSSH AuthenticationMethods](https://man.openbsd.org/sshd_config#AuthenticationMethods)。
